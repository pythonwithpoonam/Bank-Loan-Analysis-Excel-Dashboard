# Bank-Loan-Analysis-Excel-Dashboard
Analyzed bank loan data using Microsoft Excel to understand loan applications, loan amounts, repayment trends, borrower characteristics, and loan performance. Built an interactive dashboard using Pivot Tables, Pivot Charts, KPIs, slicers, and filters to provide a clear view of key banking and loan metrics.

## Key Insights
- Analyzed 4.23M customer records.
- Total loan amount analyzed: approximately 1,003.76M.
- Total payment: approximately 1,074.68M.
- Average interest rate: 12%.
- Average DTI: 12.46.
- 64% of loans were Not Verified, 28% Verified, and 8% Source Verified.
- Compared loan performance by grade and sub-grade.
- Analyzed trends by year, state, home ownership, and verification status.
